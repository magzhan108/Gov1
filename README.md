# 🏙️ Қала мәселелері (City Issues) — Азаматтық портал

Қала тұрғындарының әкімшілікке көшелердегі жол ойықтары, жиналмаған қоқыс, сынған жарықтандыру және басқа да өзекті мәселелерді фотосымен және интерактивті картадағы нақты нүктесімен тікелей жіберуіне арналған заманауи веб-портал.

---

## ✨ Негізгі мүмкіндіктері

### 👤 Тұрғындар үшін (Азаматтық бөлім):
- 📸 **Фото жүктеу:** Мәселені суретке түсіріп (немесе файл таңдап) жүктеу (автоматты түрде сапасын сақтай отырып кішірейтеді).
- 🗺️ **Интерактивті карта:** Картадан (Esri / Leaflet) мәселе орналасқан нақты орынды нүктемен белгілеу немесе маркерді қалаған көшеге сүйреу.
- ⚡ **Жылдам қала таңдау:** Астана, Алматы, Шымкент, Түркістан, Қарағанды, Ақтөбе батырмалары арқылы бірден қажетті қалаға өту.
- 💬 **Жұмыс процесін бақылау және пікір қалдыру:** Әрбір мәселенің орындалу барысына кез келген тұрғын қосымша сурет пен ақпарат қоса алады.
- 📂 **«Менің өтініштерім»:** Тұрғын өзі жіберген барлық шағымдар мен олардың қазіргі күйін жеке парақшасынан қадағалайды.

### 🏛️ Әкімшілік үшін (Admin панелі):
- 🔐 **Қорғалған кіру:** Әкімшілік панеліне тек әкімші логинімен кіруге болады.
- 📊 **Нақты уақыттағы статистика:** Барлық хабарламалар, қаралудағы және шешілген мәселелер есебі.
- 🏷️ **Статусты басқару:** Мәселе статусын тек әкімшілік қана өзгерте алады (*«Қаралуда»*, *«Шешілді»*, *«Қабылданбады»*).
- 🎖️ **Ресми жауап белгісі:** Әкімшілік қалдырған пікірлерде арнайы көк түсті **«🏛️ Ресми жауап»** белгісі тұрады.

---

## 🛠️ Қолданылған технологиялар
- **HTML5** (Семантикалық Single Page Application құрылымы)
- **CSS3** (CSS Variables, Flexbox, Grid, Responsive Mobile Design)
- **JavaScript (ES6+)** (LocalStorage деректер қоры, модальдар, валидация)
- **Leaflet.js + Esri World Street Map** (Интерактивті карта, API кілтсіз, жылдам)
- **Font Awesome 6** (Иконкалар жиынтығы)
